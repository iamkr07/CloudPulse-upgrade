# ☁️ CloudPulse  
### Cloud Resource Monitoring & Prediction Dashboard
## 🔗 Live Demo  
👉 https://cloud-resource.vercel.app/

> A cloud intelligence system that monitors infrastructure usage, predicts resource states using machine learning, and simulates scaling decisions in real time.

---

## 🧠 Overview

CloudPulse is a cloud observability and optimization platform designed to analyze system performance, predict resource utilization patterns, and recommend cost-efficient infrastructure decisions using ML + rule-based intelligence.

---

## ⚙️ Architecture

Frontend (React Dashboard)  
→ FastAPI Backend (Python)  
→ ML Engine (Random Forest Model)  
→ Decision Engine (EC2 Recommendation Logic)  
→ Dataset Processing Layer

---

## ✨ Features

### 📊 Real-Time Resource Monitoring
- Live CPU & memory visualization
- Dynamic dashboard updates
- Resource aggregation engine

### 🤖 Machine Learning Prediction Engine
- Random Forest classification model
- Resource state prediction:
  - Underutilized
  - Normal
  - Overutilized

### ⚙️ Simulation Engine
- What-if scenario analysis
- CPU & memory scaling simulation
- Instant recalculation engine

### ☁️ EC2 Recommendation System
- Smart instance mapping logic
- Cost-aware optimization
- Workload-based decision engine

### 💰 Cost Optimization Insights
- Resource cost estimation
- Waste detection analytics
- Efficiency scoring model
